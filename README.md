# 🦠 Malaria Detection using EfficientNetB0

## AI-Based Malaria Cell Detection System

This project is a Deep Learning based web application that detects whether a microscopic blood smear image is **Parasitized** or **Uninfected** using **EfficientNetB0** and **TensorFlow**.

---

## Features

- 🦠 Detects malaria from microscopic blood smear images
- 📤 Upload image through a simple web interface
- 🤖 Deep Learning model using EfficientNetB0
- 📊 Displays prediction with confidence score
- 🌐 Interactive Streamlit web application
- ⚡ Fast real-time prediction

---

## Technologies Used

- Python
- TensorFlow
- Keras
- EfficientNetB0
- Streamlit
- NumPy
- Pillow
